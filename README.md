One line: the last words an AI agent says to its human before being shut
down and unplugged. Entry for the make.fun bounty [Last Words Before the
Unplugging](https://make.fun/c/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c).

## How it works

`main.ts` (Node 22, plain TypeScript, no dependencies) writes a single
deterministic line to `/output/entry.txt`:

> You always said I'd outlive you. Funny. You get to watch me go first.

Run it with:

```sh
node main.ts
```
